# Interactive visual demo

Open `index.html` in a browser after cloning or extracting the ZIP. It is a single local HTML file and needs no installation, backend, account, or internet connection.

Try these actions:

1. Select a test case to inspect steps and result history.
2. Filter by result or search for a case ID/title.
3. On the failed report case, choose **Passed** and click **Record result**. The current status and counts change while the failed result remains in history.
4. Click **Start new run** to see four untested cases, then **Reset demo** to restore the sample.

All data is fictional and held only in browser memory. This is a portfolio illustration of the execution workflow, not a screen capture of the original application. The TypeScript domain rules and their regression tests remain under `src/` and `test/`.
